# **App Name**: NxAIO

## Core Features:

- Intelligent Tool Hub: A centralized, clean dashboard featuring an animated grid layout to access various utilities seamlessly.
- AI Logic Command Assistant: An AI assistant tool that uses reasoning to understand user intent and automatically chain specific utilities together based on natural language inputs.
- Ultra-Fast Image Optimizer: A modern drag-and-drop tool for quick compression and cropping tailored for social media assets.
- Live Creative Previewer: A real-time viewing mode that applies dynamic mockups to any content processed within the site.
- Interactive Snippet Manager: A simplified code and text snippet storage tool with modern highlighting for Gen-Z developers.

## Style Guidelines:

- Primary Color: Bone White (#F9F8F2) for a clean, sophisticated surface that feels premium and light.
- Secondary/Shadow: Deep Shadow Grey (#4B5563) to provide depth and modern contrast against the bone background.
- Modern Font: Using 'Outfit' for headlines and 'Satoshi' for body text to create a sharp, contemporary tech feel.
- Clean & Simple: A minimalist grid-based layout with generous whitespace, focusing on clarity and ease of navigation for Gen-Z users.
- Snappy Motion: Smooth, physics-based transitions and micro-interactions that provide instant feedback upon tool selection.
- Minimalist Line Icons: Ultra-thin, vector-perfect icons with a consistent stroke weight to maintain the simple aesthetic.
